# Social Media Infographics and Documentation Report

## Description

The **third output** consists of **social media infographics and a documentation report**. This project allowed me to work with information presented in a social media-friendly format while also documenting the process and results of the activity.

## Project Output

### Social Media Infographics

The infographics were designed to present information in a **clear, engaging, and visually appealing** format suitable for social media. The project focused on organizing information effectively while using appropriate visual elements to make the content easy to understand.

### Documentation Report

The documentation report records the **process, development, and results** of the activity. It provides an overview of how the infographics were created and documents the outcome of the project.

### Design Elements Applied

- **Visual Hierarchy** – Organized information to guide the viewer through the content.
- **Typography** – Used readable and appropriate fonts for social media content.
- **Color** – Applied suitable colors to make the infographics visually engaging.
- **Layout** – Arranged text and visual elements in an organized and balanced manner.
- **Information Organization** – Presented information in a concise and easy-to-understand format.
- **Documentation** – Recorded the process and results of creating the social media infographics.

## Purpose

The purpose of this project was to demonstrate the ability to **communicate information effectively through social media infographics** while documenting the process and results. It allowed me to apply visual communication principles in creating content that is both informative and engaging.
