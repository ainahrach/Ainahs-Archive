# Presentation Design Project

## Description

The **first output** is my project on **presentation design**, where I created a promotional poster for a coffee booth. This project allowed me to apply principles of visual design and create promotional material that communicates information in an attractive and engaging way.

## Project Output

### Coffee Booth Promotional Poster

The poster was created to promote a **free coffee event**. I focused on making the poster visually appealing while ensuring that the important information was clear and easy to understand.

### Design Principles Applied

- **Visual Hierarchy** – Organized information based on its importance.
- **Contrast** – Used differences in colors, sizes, and elements to emphasize key details.
- **Alignment** – Arranged elements in an organized and structured layout.
- **Balance** – Distributed visual elements evenly throughout the poster.
- **Typography** – Selected fonts that were readable and visually appropriate.
- **Color** – Used coffee-inspired colors to create an inviting and cohesive design.

## Purpose

The purpose of this project was to demonstrate how visual design principles can be applied to create effective promotional material that captures attention and communicates information clearly.
