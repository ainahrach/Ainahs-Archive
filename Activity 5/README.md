# Activity 5: Exploring AI Tools Through Prompt Engineering

## About the Activity

This repository contains the output for **Activity 5: AI Tools**, which explores the use of artificial intelligence in generating visual concepts through text-based prompts.

The activity demonstrates how AI image generation can transform written instructions into visual representations and how refining prompts can improve the generated output according to specific preferences and design requirements.

## Project Overview

### Pilates Studio Concept

The main objective of this activity was to conceptualize a Pilates studio using AI-generated images. The process involved two prompts, with the second prompt introducing additional design specifications to enhance the initial concept.

### Prompt 1: Initial Concept

**Prompt:** 
> Make me a Pilates Studio.

The initial prompt generated a minimalist Pilates studio featuring:
- Six light-wood reformer machines arranged in rows.
- Natural oak flooring and clean white walls.
- Large windows overlooking a garden.
- A bright, peaceful, and minimalist atmosphere.

### Prompt 2: Refinement and Customization

**Prompt:**
> Make a Pilates studio with earthy tones of green, beige, baby pink, and other colors that would fit the motif. Make the ambience calm and relaxing with appropriate lighting that isn't overstimulating. I also want to add a mini cafe that serves a variety of coffee and matcha.

The second prompt refined the original concept by incorporating:
- **Color Palette:** Sage green, beige, baby pink, and complementary earthy tones.
- **Interior Design:** Warm wooden elements and coordinated studio furnishings.
- **Ambience:** Calm, relaxing, and comfortable lighting.
- **Additional Feature:** An integrated mini café offering coffee and matcha.

## Output and Results

The two generated images demonstrate how additional details and specific instructions can influence AI-generated visual outputs.

The first image establishes the basic structure and layout of the Pilates studio, while the second transforms it into a more personalized concept by incorporating the requested color palette and café area.

The final output presents a functional and aesthetically cohesive Pilates studio concept where fitness and café culture coexist.

## Key Takeaways

Through this activity, I learned that:
- AI tools can transform simple text prompts into visual concepts.
- Specific and descriptive prompts help generate outputs that better align with a desired vision.
- Refining prompts allows users to modify and improve initial AI-generated results.
- AI can serve as a creative tool for brainstorming, visualization, and conceptual planning.
